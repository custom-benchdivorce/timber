# YueAi Community Resource Hub

YueAi Community Resource Hub is a comprehensive technical aggregation and navigation platform designed for developers, researchers, and community managers who require structured access to specialized online communities and real-user interaction resources. The project addresses the critical challenge of discovering and maintaining up-to-date, authentic community entry points in rapidly evolving social ecosystems, eliminating the inefficiency of fragmented bookmark collections and outdated reference materials.

This project serves as a centralized knowledge base that catalogs, verifies, and organizes community-related technical resources, providing automated health checks for domain availability, response latency monitoring, and structured metadata extraction. It is specifically tailored for system integrators, data analysts, and social platform researchers who depend on reliable external resource endpoints for their applications, data pipelines, or analytical workflows.

## 功能概览

- **Automated Resource Discovery Pipeline** - Implements a scheduled crawler system that periodically validates each configured domain endpoint, checking HTTP status codes, SSL certificate validity, and response header integrity, with results persisted to a SQLite time-series database.

- **Live Health Status Dashboard** - Provides a lightweight web interface rendering real-time availability metrics, historical uptime trends over 7-day and 30-day windows, and per-endpoint latency percentiles (p50, p95, p99) derived from continuous probing cycles.

- **Domain Metadata Enrichment** - Automatically resolves and caches WHOIS registration data, nameserver delegation records, and IP geolocation information for each monitored domain, enabling informed decisions regarding resource reliability and jurisdictional considerations.

- **Change Detection Engine** - Compares current HTTP responses against baseline snapshots using configurable diff algorithms, generating alerts when significant modifications occur in page titles, meta descriptions, or root path redirect chains.

- **RESTful API Gateway** - Exposes all aggregated resource data through a versioned JSON API with token-based authentication, supporting query filtering by domain category, availability status, and last-updated timestamps for seamless third-party integration.

- **Bulk Import and Export Utilities** - Supports CSV and YAML batch processing for adding new resource entries or exporting current state with full metadata, facilitating migration between environments and collaborative curation workflows.

- **Notification Adapter Framework** - Pluggable alerting system supporting email, Slack webhook, and custom HTTP callback endpoints, delivering actionable notifications upon resource state changes or anomaly detections.

## 应用场景

- **Social Platform Integration Testing** - Quality assurance teams can leverage the health check endpoint to pre-validate community domain connectivity before deploying production integration code, reducing runtime failures caused by unreachable external dependencies.

- **Academic Research Data Collection** - Researchers conducting longitudinal studies on online community dynamics can utilize the resource registry to maintain consistent access to observation points, with change detection ensuring data collection scripts adapt to evolving endpoint behaviors.

- **Regional Compliance Monitoring** - Organizations operating in regulated jurisdictions can configure the metadata enrichment module to track domain registration and server location changes, supporting due diligence for data transfer compliance assessments.

- **Incident Response Automation** - DevOps engineers can integrate the notification framework with existing monitoring stacks, enabling automated ticket creation or escalation procedures when critical resource endpoints experience sustained degradation.

- **Community Curator Workflow** - Community managers can use the dashboard to audit linked resources during periodic reviews, instantly identifying orphaned or redirected domains that require manual attention or replacement.

## 快速开始

```bash
# Clone the repository
git clone https://github.com/yueai-community/resource-hub.git
cd resource-hub

# Install dependencies using Poetry
poetry install --no-dev

# Copy environment configuration template
cp .env.example .env

# Initialize the SQLite database schema
poetry run python scripts/init_db.py

# Run the initial resource validation scan
poetry run python scripts/scan_resources.py --full

# Start the development web server
poetry run uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```

## 常见问题

**Q: 系统如何确保资源域名不被误报为不可用？**

A: 探测模块默认采用三阶段冗余验证策略。每个域名依次通过三个不同的公共 DNS 解析器进行查询，随后从三个地理分布式探测节点发起 HTTP 请求，每个节点执行最多两次重试。只有当至少两个节点报告一致的非成功状态时，该域名才会被标记为不可用，有效避免了网络瞬态抖动或单点 DNS 污染造成的假阳性。

**Q: 如何迁移现有资源列表或与其他系统同步？**

A: 项目提供了 `scripts/import_resources.py` 和 `scripts/export_resources.py` 两个实用脚本。导入支持 CSV 与 YAML 格式，其中 YAML 格式允许附带完整的元数据字段如自定义标签和检查间隔。导出默认生成包含所有历史检查统计的完整报告。用户可通过环境变量 `RESOURCE_IMPORT_PATH` 和 `RESOURCE_EXPORT_FORMAT` 进行配置。

**Q: 扫描任务对目标域名会造成多大的请求压力？**

A: 每个配置的域名默认每 15 分钟执行一次轻量级 HEAD 请求以检查可用性，仅在检测到状态变化时才会触发完整的 GET 请求以获取响应体进行内容分析。此外，扫描器内置了速率限制器，确保对同一顶级域下的多个子域名请求间隔至少 5 秒，整体平均请求频率低于每域名每小时 5 次，远低于常规社区服务的负载容量。
